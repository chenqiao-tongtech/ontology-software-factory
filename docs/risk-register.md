# 软件工厂首版风险登记表

| ID | 风险 | 发生信号 | 影响 | 预防/响应 |
|---|---|---|---|---|
| R-01 | 范围膨胀 | 未评审增加产品/Agent/工具/权限 | 计划失控 | 更新 scope manifest、影响分析、ADR 和验收条件 |
| R-02 | 本体过度建模 | 没有能力问题仍新增概念 | 维护成本/语义漂移 | 能力问题驱动，核心与候选扩展分离 |
| R-03 | 虚假成功 | Agent 自述测试/扫描/部署成功 | 不合格产物放行 | 只采信实际执行器结果与版本化报告 |
| R-04 | 权限边界失效 | 工具默认开放或凭证过大 | 数据/系统损害 | 默认拒绝、短期凭证、策略、审批、审计与限额 |
| R-05 | 资产来源不可信 | 示例元数据被当作签名/兼容证据 | 供应链风险 | 占位数据明确标注，真实来源与摘要校验另设验收 |
| R-06 | 外部依赖不可用 | API/扫描器/Git/环境缺失 | 结果不完整 | 显式 blocked/incomplete；Fake 测试不能冒充真实集成 |
| R-07 | 契约漂移 | ID、状态和错误语义分裂 | 回写错误、重复执行 | 统一 Schema/事件 ID，契约与集成回归测试 |
| R-08 | 成本无法归因 | 费率/工具耗时/人工介入缺失 | 无法比较收益 | usage ledger；未知价格不记为零，建立人工基线 |

| R-09 | 多 Agent 循环、职责重叠或相互确认造成假共识 | 任务反复交接、证据冲突被忽略、生成者自我批准 | 成本失控或不合格候选被放行 | 确定性控制器、Typed Handoff、循环/预算上限、独立验证与人工升级 |

风险关闭必须引用可重复的证据，不能仅凭“模块已经编码”而关闭。
