# 工作流运行时与控制台验收清单

## 定义
- [ ] 工作流版本为不可变版本；运行实例固定引用定义版本。
- [ ] 节点 ID 唯一；所有依赖都指向已定义节点；依赖图无环。
- [ ] 每个节点有 owner/role、执行模式、输入输出 Schema、超时、最大尝试次数与证据要求。
- [ ] 外部副作用节点声明幂等键与补偿策略。

## 状态机
- [ ] 依赖未完成时不能启动后续节点。
- [ ] `complete_step` 只能作用于当前 running 节点。
- [ ] 人工审批仅能在指定审批门发生；审批和拒绝都要求理由并记录操作者。
- [ ] 非瞬时、确定性错误不会自动重试。
- [ ] 超出最大尝试次数后，重试命令会被拒绝。
- [ ] 终态运行不能被取消、恢复或重新推进。
- [ ] 并发操作采用 revision 检查，旧版本更新不能覆盖新版本。

## 持久化 / 事件
- [ ] Run 状态和对应事件在同一事务提交。
- [ ] 服务重启后 Run/Step 状态与事件保留。
- [ ] 每次重试都是新的 attempt，原失败事件不会被覆盖。
- [ ] 不在事件 payload 中存放明文 Secrets、客户机密或完整的敏感上下文。

## UI
- [ ] 列表展示运行 ID、标题、状态、当前节点/进度与更新时间。
- [ ] 节点视图展示依赖、角色、状态、尝试次数、错误与证据。
- [ ] 按钮状态根据后端 Run/Step 状态决定；后端再次验证，不信任前端。
- [ ] 批准/拒绝提供理由，并在事件时间线展示操作者和时间。
- [ ] 错误与冲突以可读消息显示；没有成功响应前不乐观宣告操作完成。
- [ ] 演示 UI 明确标注模拟行为，不冒充真实 CI/CD 或 LLM 执行。

## 生产化尚待实施
- [ ] 身份验证、RBAC/ABAC、租户隔离、密钥管理与 CSRF 防护。
- [ ] Worker/队列、Outbox、去重、定时器、超时、心跳、重试退避和补偿执行器。
- [ ] 真实 Evidence URI/摘要、CI 状态、模型/Skill 版本、成本和 Trace 关联。
- [ ] 数据库备份、迁移、保留周期、告警、限流与灾难恢复演练。
