# ADR-0002：优先组合现有工程工具，不重复建设基础设施

- 状态：Accepted（本系列参考实现的设计决定）
- 日期：2026-10-27

## 背景

代码托管、CI/CD、测试框架、安全扫描、制品库和部署系统已有成熟实现。重新构建这些能力会增加维护成本，也会分散软件工厂的差异化投入。

## 决策

将既有系统通过 `adapters/` 集成；优先自行掌握：

- 统一领域语义与产品资产模型；
- Agent 任务契约、状态和错误语义；
- 跨工具工作流和策略门禁；
- 构建、测试、漏洞和制品的证据追溯；
- 面向客户交付的版本与配置治理。

## 后果

- 通过标准接口替换工具供应商时，降低对核心业务语义的影响。
- 需要维护适配器、身份认证、接口兼容和外部服务故障处理。
- 选型必须通过同一组 POC，而不能仅根据宣传页或单次演示决定。
