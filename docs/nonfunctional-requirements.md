# 非功能要求（NFR）

| ID | 属性 | 要求 | 验收方式 | 首版强度 |
|---|---|---|---|---|
| NFR-01 | 安全与隔离 | 默认拒绝、最小权限、客户边界和密钥引用 | 越权/路径穿越/秘密泄露负向测试 | 强制 |
| NFR-02 | 正确性与证据 | 结果绑定输入版本、运行记录、报告与摘要 | 缺证据、错版本、重复事件必须被拒绝 | 强制 |
| NFR-03 | 可靠性与恢复 | 幂等、有限重试、超时、取消、暂停恢复、未知结果对账 | 故障注入和恢复演练 | 强制 |
| NFR-04 | 互操作性 | 外部工具通过契约和 Adapter 接入 | 契约测试、fixture 和真实连接测试分开记录 | 强制 |
| NFR-05 | 可维护性 | 单一职责、依赖可检查、决策有 ADR | 架构基线校验和依赖环测试 | 强制 |
| NFR-06 | 可观测性与审计 | run/task/attempt、耗时、退出码、错误、审批和证据关联 | 可重建关键时间线，日志避免泄露秘密 | 强制 |
| NFR-07 | 成本可核算 | 记录模型/工具/执行/人工成本 | 费率未知时显式显示 unknown | 基线建立阶段 |
| NFR-08 | 性能与容量 | 建立延迟、排队、工具耗时和并发基线 | 运行真实 POC 后制定目标，不提前虚构 SLA | 基线建立阶段 |
| NFR-09 | 可演进性 | 本体/Schema/Workflow/Role/Skill/工具具备版本策略 | 兼容/迁移和弃用测试 | 强制 |

性能与成本目标须以真实任务建立基线后由产品和平台负责人确认。本文不为尚未测量的系统设定虚构的数字目标。

| NFR-10 | 多智能体可控性 | 团队拓扑、Agent 跳数、并行数、修复循环、工具/模型预算必须有界；独立验证和审批不能被生成 Agent 绕过 | 拓扑 Schema、非法 handoff、越权与循环上限负向测试 |
