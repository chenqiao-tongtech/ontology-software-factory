# Software Factory Domain Evidence (synthetic fixture)

An explicit Requirement has acceptance criteria and targets a Product.
A Component has a stable Version.
A Build is created from a source revision and a Component Version.
A TestRun validates a Build.
A successful TestRun has zero failed tests.
An Artifact is produced by a Build and carries a SHA-256 digest.
A Release contains Artifacts and must be linked to test and security evidence before it is eligible for publication.
