# Agent Handoff Example

`requirement-task.json` and `requirement-result.json` are schema-shape examples for documentation and static validation.

The ontology digest, snapshot ID, Role digest and Skill digest values in these two files are **syntactically valid placeholders**, not a cryptographic attestation of the repository's current ontology or Skill files. Real runtime Task/Result contracts are generated by `ontology_runtime.py` from the active approved Portal snapshot and the current Role/Skill files, and their digests are recomputed before execution.
