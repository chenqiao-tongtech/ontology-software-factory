# Workflow Run examples

At first startup, `scripts/run_workflow_console.py` inserts three demonstration runs into an empty SQLite database:

- `RUN-1048`: waiting for a human to approve release; the deployment node cannot start before approval.
- `RUN-1047`: failed because the test worker lost its heartbeat; the failed attempt can be retried in demo mode.
- `RUN-1046`: completed run with placeholder evidence.

These are generated by `seed_demo_runs()` and intentionally use placeholder evidence. They demonstrate state and console interaction, not actual project/test/deploy results. If you want the latest seed set again, stop the server and delete the local SQLite database.
